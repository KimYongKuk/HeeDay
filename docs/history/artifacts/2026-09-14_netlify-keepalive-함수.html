작은 커밋을 따로 push 하지 말 것

push 한 번이 월 예산의 5%. 크레딧이 0 이 되면 리셋일까지 사이트가 정지된다. Deploy Previews · Branch deploys 도 같은 단가라 켜지 않는다.

8월 장애 원인은 아직 가설

크레딧 고갈이 콜드 스타트보다 유력하지만 Usage 의 8월 기록을 아직 보지 않았다. 확인 전에 단정하지 않는다.

cron 은 UTC

22-23,0-10 이 KST 07–19시다. "왜 밤에 도냐"고 고치면 근무시간에 안 돈다. 주말은 cron 이 아니라 함수 첫 줄에서 KST 요일로 거른다 (UTC 창 한가운데 요일 경계가 있어서).

함수 웜 유지는 보장값이 아님

15분 주기면 가끔 함수 콜드 스타트가 샌다. 로그의 totalMs 가 5초 넘게 튀면 그것. dbMs 가 커지면 TiDB 쪽. 잦으면 10분으로 좁힌다.
